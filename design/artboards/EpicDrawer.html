Scope

Close the loop between a decomposed ticket and a merged pull request. A Coder Agent claims a ticket, mints an ephemeral E2B sandbox, clones formic-web with a scoped PAT, writes code inside its assigned file boundary, runs the suite, and pushes a branch. The Reviewer Agent then watches the PR, feeds failing CI logs back into a bounded fix loop, rebases onto main, and merges one PR at a time.

Technical requirements

  • Durable orchestration through Inngest, so a sandbox that dies mid-run resumes rather than restarting the ticket.
  • Every agent run is bounded: 20 minutes wall clock, 3 fix attempts, one file scope.
  • Sequential merge for V1 — the Reviewer Agent holds a single merge lock and runs git pull --rebase before each merge.

User stories

As a founder, I drag an epic into To Do and come back to merged PRs, not to a queue of decisions.

As a reviewer, I can open any ticket mid-flight and read the live terminal instead of guessing why it stalled.
