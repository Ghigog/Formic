Drag a card and it stays put

Column position is written to Postgres on drop, so a reload rebuilds the board exactly as you left it. Ordering is a fractional index, which means two agents moving cards at once no longer fight over integers.

Five columns, one responsive grid

The board collapses to a swipeable single column under 768px. Below that width the drag handles are replaced by an advance button, so the same board works on a phone.

3

Epics and tickets share one schema

An epic is a ticket with children, which is what lets the Architect Agent attach a DAG without a second table. File scopes are stored alongside each child, ready for the execution loop.
